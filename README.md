# Portfolio Website

A responsive personal portfolio website that showcases my projects, skills, certifications, and design work. Built from scratch using HTML, CSS, and JavaScript with a focus on clean UI, smooth interactions, and accessibility.

## Features

- Responsive layout for mobile, tablet, and desktop
- Clean, modern UI with smooth scroll and subtle animations
- Projects section with descriptions and links
- Skills and certifications overview
- Contact section for reaching out

## Tech Stack

- **HTML5**: semantic structure
- **CSS3**: Flexbox, Grid, custom properties, media queries
- **JavaScript (ES6)**: interactivity and DOM manipulation

## Getting Started

1. Clone the repository
```bash
   git clone https://github.com/Jeropaul360/Portfolio.git
```
2. Open the project folder
```bash
   cd portfolio
```
3. Open `index.html` in your browser, or use a local server like Live Server in VS Code.
